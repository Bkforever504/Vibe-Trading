# CISD shadow attribution

The detection concept and lifecycle rules are derived from **cephxs / CISD
[base]**, published by cephxs / fstarcapital under the Mozilla Public License
2.0. This derived detector remains under MPL-2.0; see the SPDX header in
`agent/analytics/cisd_shadow.py`.

Source: https://www.tradingview.com/script/zzL17fzY-cephxs-CISD-base/

The integration intentionally excludes chart drawing and Fibonacci projections.
It adds no TradingView or Discord alert automation and has no order authority.
