# Learning Loop Edge Upgrade

Date: July 20, 2026

## Problem Found

The learning loop retained 129 immutable mistake events but collapsed most
directional shadow losses into one generic entry-confirmation pattern. It also
listed repaired evaluator mismatches as active challenger nominations. That
created memory without enough useful diagnosis.

## Upgrade

The loop now clusters directional failures by:

- strategy and option direction;
- opening, midday, or late session;
- ORB entry pattern and retest status;
- directional VWAP/EMA alignment;
- expected-move consumption bucket;
- entry spread bucket.

It aggregates those clusters into a small challenger portfolio. Repaired or
decaying defects remain in immutable history but cannot nominate active trials.
No learned lesson can change production parameters or submit orders.

## First Useful Contrast

Cost-adjusted completed shadow outcomes currently show:

| Cohort | Completed | Trading days | Win rate | Average contract return |
|---|---:|---:|---:|---:|
| Fresh confirmed ORB retest | 6 | 1 | 66.7% | +17.742% |
| Raw or unconfirmed ORB breakout | 71 | 1 | 26.8% | -18.551% |

The observed fresh-minus-raw difference is +36.293 percentage points. This is
not proof because every outcome came from one trading day and option-contract
returns are not account P&L.

The existing live-candidate path already requires a fresh confirmed retest.
The result therefore supports preserving that safety gate, not changing the
bot today.
